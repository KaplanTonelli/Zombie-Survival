# Project: Text Adventure
Develop an interactive, text-based experience that is implemented using Python. In this repository, you will implement the experience, but you should also include an accompanying plan in your portfolio.

## Requirements
Build an experience that:
- Accepts input from the player.
- Uses that input to affect what happens in the program.
- Includes at least three meaningful player decisions.
- Includes multiple possible outcomes.
- Produces clear output that allows the player to understand the situation and available choices.
- Follows the Creative Computing Python Style Guidelines.
- Runs from beginning to end without errors during normal use.

## Testing and Revision
Test your program throughout development. You should:
- Test each major path through the experience.
- Identify and correct syntax, runtime, and logic errors.
- Test likely unexpected input.
- Have another person play your experience.
- Revise your program based on testing and feedback.
